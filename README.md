# My First Prompt 🌟

This is my first HTML project!  
It displays a simple greeting message with a waving emoji.

## Features

- Shows the message: "My name is Peculiar 👋"
- Welcomes users to my first prompt
- Thanks Goodwall for the opportunity

## How to Open

1. Clone or download this repository.
2. Open index.html in your web browser.
3. Enjoy the message!
